# ADR 011: Server-sent events instead of WebSockets for live updates

**Status:** accepted (implementation in 0.3) · 2026-11-10

**Decision.** Live updates for the notification center and the dispatch board use server-sent events from Next.js
route handlers, fed by PostgreSQL or Redis pub/sub, with a 30-second heartbeat.

**Consequences.** Works through Cloudflare and nginx (`proxy_buffering off` on `/api/v1/stream`), no separate
WebSocket server.
